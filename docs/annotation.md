# P3.3 纯文本标注与频率筛选

`annotate_ips(text)` 和 `annotate_ips_with_skip_top(text, skip_top)` 已接入正式离线资源。
已实现分词、直接采用的 IPS、字符簇对齐、大小写、未知词中括号，
以及 `the` 上下文、缺源后的缩写/复合/词形推导和高频词/短语屏蔽。
本阶段不是 P4 全量差分或性能验收。

## 扫描与资源

- 先检查负阈值，再检查 NUL；空文本和首尾空白合法。
- 扫描集合为固定 Python 3.12.4 / Unicode 15.0 的 `isalnum()` 加全部 `M*` 类别。
  词内 `-'’` 只在已有词段且后继标量为 Python `isalpha()` 时连接。
- 仅整个词段匹配 `[A-Za-z]+(?:[-'’][A-Za-z]+)*` 才转换。
  数字、非英语字母、Mn/Mc/Me 或变体选择符会使相连的整个词段原样保留。
  Rust 内部使用 UTF-8 字节区间，区间始终落在标量边界。
- 没有完整英语词段时，对任意非负阈值直接返回输入，不调用资源加载器。
  有英语词段且阈值为零时只加载主词库；损坏/不兼容错误原样传播并按加载器规则缓存。
- 有英语词段且阈值大于零时，按 `min(skip_top, 5062)` 先加载并验证频率，再加载主词库。
  即使全部词被屏蔽仍传播主词库错误；正阈值不再返回 NotImplemented。
- 原样复制所有词段间隙，保留 CR/LF、制表符、标点和非英语文本。
  本函数处理纯文本，不解析 HTML；标签中的英语也会作为纯文本处理。

## 直接匹配与转换

按精确原词、弯撇号换直撇号、原词小写、小写直撇号四种拼写依次查询，去除重复。
首个存在词条立即停止，即使其状态是允许缺源回退或明确阻断。
标注输入域仅含 ASCII 字母及三个分隔符，因此 ASCII 小写与 Python 的小写等价；
不调用简单查询的 `lower_variant`。`APPLE` 可以标注，简单查询仍遵守其原有回退限制。

从 `AnnotationState::Available` 读取单个有效采用 IPS，按 `M*` 分组为完整字符簇。
每个输入标量须与一个字符簇对齐，基础字母须相同。分隔符输出输入原样，
英语字母依输入逐字大小写转换，支持全部 52 个双线体形式及精确的 `w̄ ↔ W̅` 特例。
未知词、不可用/阻断词条、长度或基础字母不匹配均输出 `[原词]`。
`Fallback` 与 `Absent` 保留不同内部状态，均允许进入下述文本推导；
明确 `Blocked` 先于上下文、明确缩写、拆词和词形规则返回中括号。

NFD 只用于**判断能否对齐**，输出始终对原始字符簇作完整大小写转换，不输出规范化字符串。
允许的 NFD 附加标记为 U+0300、0302、0303、0304、0305、0307、030A、0323。
生成表固定 243 个可用 NFD 基础标量、9 个可用附加标量（包含分解成 U+0300 的 U+0340），
以及 54 个精确特殊字符簇。附加标量的大小写均为恒等；规范化重排不影响集合判断，
因此初始标量及各后续标量的受限 NFD 谓词等价于 Python 的整个字符簇判断。
双线体加附加标记不属于精确特例，会被拒绝。无需实现或依赖通用 NFD 运行库。

## 上下文、复合与词形

- 状态检查后，`the` 按紧邻下一完整英语词段的首字母 a/e/i/o/u 使用 `ṫhē`，
  否则使用 `ṫhe̊`，再匹配输入大小写。它优先于保存的可用值；这是字母规则，
  `hour` 用短式而 `university` 用长式。不跳过中文、数字或带组合符的紧邻词段。
- 上下文只跨 Python 的 29 个空白标量及 `" ' ‘ ’ “ ” ( ) [ ]`。
  与参数验证共用显式固定空白表，不依赖编译器 Unicode。
  空行精确按 Python `\n\s*\n` 判断：单 LF、两个 CR、U+2028/U+2029 均可跨，
  LF + 空白 + LF 中断；LF + 引号 + LF 可以跨。逗号、花括号、尖括号等中断。
- 其他已有可用整词值优先；对齐失败直接标未知，不继续拆分或推导。
  缺源后才使用 don't、doesn't、aren't、I'm、you're、o'clock 六个明确规则，
  规则注记与固定 Python 完全相同，并恢复输入大小写和直/弯撇号。
- 连字符按段转换，未知段单独加括号。各段的上下文是下一段原文，
  最后一段继承外层上下文。完整复合词的阻断状态禁止拆分。
- 其他撇号词优先尝试 `n't` 前的词干，再尝试第一个撇号前段。
  前段转换不继承外层上下文；成功后后缀按输入原样保留。
  UTF-8 输入先把 Python 字符位置映射回字节边界；弯撇号与多个撇号可混用。
  前缀搜索用显式堆栈维持 Python 的深度优先顺序，避免超长合法词段耗尽原生调用栈。
- s/es/ed/ing 根据反生成拼写候选，处理辅音后 y、尾 e、ie→y、双写及 bus、
  age/singe/tinge/queue 等固定例外；不增加 Python 以外的语言学过滤。
  候选先按输入对应位置确定大小写，再查询和对齐；只保留仍对应原字母的完整字符簇，
  改变或新增字母用原拼写，不推断后缀发音。
- 任一词干候选命中 `Blocked` 即阻断整个推导；缺源、缺词或无法对齐的候选忽略。
  全部可用候选的最终输出去重后恰好一个才采用，多个不同输出保留 `[原词]`。
  推导不进入共享索引，单词查询和数据文件不变。

## 原始频率与保护区

- 频率键使用 P2.1 固定资源中的原始最小 NUMBER，包含 LEMMA 和已存 INFLECTIONS。
  不按行数解释、不压紧序号缺口，不把任意词干的所有推导词形自动加入屏蔽。
  NUMBER=30 的缺口、重复词的最早序号及 `winded ; wind` 等原始形式保持不变。
- 完整英语词先按原词小写和直撇号规范形式查询频率；屏蔽命中时保留输入原词，
  优先于 Blocked、the、可用注记和全部回退。连字符各段、撇号前缀共享同一筛选状态；
  inflected 的候选词干仍只依保存的注记推导，不因为词干高频就跳过整个输入。
- 所有 10,620 个固定频率键均为小写 ASCII，26 个不符合完整英语词模式的形式包括
  带标点缩写、数字及短语。频率初始化时一次建立只读特殊索引并共享复用；
  v1 匹配层明确检查 ASCII 键域，非 ASCII 键报资源错误，不假称通用 Unicode 正则支持。
- 特殊索引按 Python 字符长度降序、相同长度按原词排序；固定 ASCII 域的字节长度/排序
  与该业务顺序一致。扫描按最左起点、同起点首个可匹配项推进，匹配后即消费整个区间，
  即使后续小写成员或边界检查拒绝，也不改试较短项或重叠起点。
- 字面匹配实现固定 CPython 3.12 的 ASCII pattern `re.IGNORECASE` 域：ASCII 大小写
  加 İ/ı/ſ/K 四个标量；随后 `str.lower()` 成员检查拒绝前三个，允许 K→k。
  这保留了“正则命中但成员拒绝仍消费”的行为，无新增正则或 Unicode 依赖。
- 保护区两侧若为固定 Python isalnum、M* 或 `-'’` 则拒绝；下划线、零宽空格、
  emoji 等按原规则处理。短语的空格是字面空格，不合并空白或跨行匹配。
- 在未保护片段重新扫描，保护区作为完整 span 原样输出；the 上下文只看重建后的
  下一 span，因此不会从 `a.m.` 等保护区内部借用英语首字母，也不把邻接未知词一起屏蔽。

## 可重复性与验证

[Unicode 身份](annotation-unicode.json)记录 Python/源代码/许可/生成器身份及表摘要。
`tools/generate_annotation_unicode.py --check` 拒绝基线、解释器、参考许可或现有输出漂移。
Unicode 表约 40 KB，沿用 [Unicode License V3](../third_party/unicode/LICENSE.txt)，无新增 Cargo 依赖或 MSRV 要求。
Rust 不调用编译器的 Unicode 分类、大小写或规范化实现。

`tools/generate_annotation_vectors.py --check` 直接从固定 Python 捕获预期，核对完整输入身份；
现有 P0 文件不变。向量包含 83 个扫描输入、497 个基础判定、1,024 个字符簇转换，
其中覆盖全部 298 个单标量可接受基础和全部双线体形式。
公共测试包含 5 条固定 P0 及 10 条直接标注/无词段文本，默认和显式零阈值共 30 次完整输出核对。
生成器按 Python 保存状态检查文本无需成功的 P3.2 推导，不通过比较 Rust 输出来选择样本。

Rust 还逐一核对全部 1,112,064 个 Unicode 标量的扫描/NFD 域/有效大小写摘要；
独立 wire 夹具覆盖首个存在词条阻断、精确大小写/撇号优先、错误与无法对齐路径。
公共测试覆盖所有权及 16 线程并发，损坏资源测试覆盖真正的分词无资源路径和零阈值无频率路径。
独立只读复核另外对全部标量及 200,000 组确定性组合字符簇核对 Python，未发现算法差异。
